# C++ Template

Starter files for C++ competitive programming solutions.

## Files

- `hello_world.cpp`: minimal output example
- `main.cpp`: neutral starter entry file
- `build/`: placeholder directory for local binaries

## Build And Run

> [!NOTE]
> Git does not track empty directories, so a fresh clone has no `build/` folder yet. Create it first with `mkdir -p build`.

```bash
g++ main.cpp -o build/main
./build/main
```
